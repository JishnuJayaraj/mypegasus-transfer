# ADR-0007: Authentication

- Status: Proposed
- Date: 2026-10-15

## Decision
- Staff: OIDC through the `IdentityProvider` adapter (provider open — Entra ID likely).
  Dev/test: stub provider with a user switcher.
- Participants: passwordless magic link via email or SMS, short-lived, single-use; session
  scoped to own data only.
- Authorisation: role × project, checked in the API for every request; never in the UI only.

## Consequences
- Participants without email/phone need assisted mode (open question #11).
