# Open questions

The questions still `open`, `assumed` or `verify`. Add questions here instead of guessing. When
a question is answered, record the answer in a dated file in [`decisions/`](decisions/), update
the relevant doc, and update the row here; once it is `confirmed`, move the row to
[`decisions/settled-questions.md`](decisions/settled-questions.md). Question numbers never
change, so `Qnn` in code and docs finds its row in one of the two files.

**Status values**
- `confirmed`: confirmed by the owner (or by a primary source such as the official form or the
  law), with name/source and date in the last column.
- `assumed`: a working answer we build on, **not yet confirmed by the owner**. It must not be
  written into CLAUDE.md or data-protection.md as fact.
- `verify`: assumed, and contains a factual point that must be checked before it goes live.
- `open`: no answer yet.

**Gate:** before the pilot, nothing in the categories data protection, retention or legal
deadlines may be `assumed` or `verify` (rows marked 🔒). A confirmation should normally change
policy tables, configuration and tests; if a reviewer requires a design change, real data stays
blocked until it is implemented (round 9).
